# Mini Internet Protocol Stack Simulator

This project implements a simplified network protocol stack simulator in Python.

## Files

- `main.py`: Entry point of the program.
- `config.py`: Stores IP addresses, MAC addresses, constants, and MAC tables.
- `protocol.py`: Defines Layer 2 Frame, Layer 3 Packet, and Layer 4 Segment.
- `devices.py`: Implements Host and Router behavior.
- `README.md`: Project explanation and running instructions.

## How to Run

```bash
python3 main.py 1200
